Où le coller

  1. Dans Supabase, ouvre ton projet.
  2. Menu de gauche → SQL Editor → New query.
  3. Colle, puis Run (ou Ctrl+Entrée).
  4. Tu dois lire Success. No rows returned. C'est le résultat normal : le script crée des tables, il ne renvoie pas de lignes.
